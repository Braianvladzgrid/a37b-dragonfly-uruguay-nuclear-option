# Primary references and current state

- FAU Museo Aeronautico A-37B fact sheet:
  https://museo.fau.mil.uy/aeronave/fichas/cessna_a-37_b
  Describes two seats side by side, twin J85-GE-17A engines, tricycle
  retractable gear, tip tanks and the Uruguayan FAU 284 example.

  https://sourceforge.net/p/flightgear/fgaddon/19674/
- Exact downloaded tree (global repository revision 21797):
  https://svn.code.sf.net/p/flightgear/fgaddon/!svn/rvr/21797/trunk/Aircraft/Cessna-A37-Dragonfly/
- USAF museum reference:
  https://www.nationalmuseum.af.mil/Visit/Museum-Exhibits/Fact-Sheets/Display/Article/196046/AFmuseum/cessna-a-37-dragonfly/

  its dimensions/engine/weight figures to the Uruguayan A-37B.
