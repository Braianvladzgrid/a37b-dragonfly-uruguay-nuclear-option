# A-37B Dragonfly - Uruguay

Project started: tier 1, $13,000,000. This is source preparation, not a playable mod.

The pinned FlightGear source includes the aircraft, cockpit, instruments, seats
and pilots. SourceAssets retains the original archive, license and SHA-256
manifest. Assets/Blueprinter/Mods/A37B/Models holds converted OBJ/MTL assets once
SourceAssets/convert_models.py completes. See CREDITS.md.

Planned: historical FAU livery, dedicated silhouette, two seats side by side,
tricycle gear animation, dry twin turbojets without afterburner, and native game
weapons/HUD. The exact donor, hardpoint geometry and mass distribution must be
validated before a playable bundle is produced.

Acceptance checks will use a noncombat scenario with normal damage and physics.
Do not classify post-impact self contacts as spontaneous structural failure.
Public release requires source/texture attribution, a new spawn, takeoff,
gear/camera cycling, power changes, weapon firing and a landing/brake check.
